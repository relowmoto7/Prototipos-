# Protótipos públicos

Este repositório contém demonstrações visuais para testes de layout e navegação. Não coloque aqui código privado, regras internas, credenciais, tokens, chaves de API ou dados pessoais.

## Estudos Digital

O arquivo `index.html` é um protótipo demonstrativo, sem cadastro real, backend ou integração com IA. Os dados de teste ficam somente no navegador de cada pessoa.

O site é publicado pelo GitHub Actions usando GitHub Pages.
